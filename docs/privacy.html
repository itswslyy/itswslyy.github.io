Privacy Policy

wslyy autopilot · Last updated 18 November 2026

wslyy autopilot is a private tool used only by its owner, the creator behind the Instagram account @wslyyofficial and the YouTube channel wslyyofficial. It reposts the owner's own videos and photos from their own Instagram account to their own Facebook Page and YouTube channel on a schedule.

Who uses it

Only the owner. The tool is not offered, sold or made available to anyone else, and nobody else can sign in to it.

What data it uses

  • The owner's own posts (video and image files and captions) from the owner's own Instagram account.
  • The owner's own login tokens for Instagram, Facebook and YouTube, stored as encrypted secrets and used only to publish to the owner's own accounts.
  • From YouTube: it uploads videos to the owner's channel (YouTube Data API videos.insert) and reads the owner's own channel name (channels.list) to confirm the right channel is connected.

What it does not do

  • It does not collect, store or share any data about other people or other YouTube users.
  • It does not display YouTube data to anyone.
  • It does not sell data, show ads, or use data for any purpose other than publishing the owner's own content.

Data storage, retention and deletion

  • The tool keeps no copies of videos after uploading: each file is downloaded, uploaded and discarded within the same run.
  • The only things it keeps are the owner's login tokens and a log of the owner's own recent posts (links and times, limited to the latest 300 entries; older entries are deleted automatically).
  • To delete everything: revoke access at Google security settings, delete the stored secrets and clear the post log. No YouTube data is kept anywhere else.

YouTube API Services, Google and YouTube

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy. Access can be removed at any time from Google security settings.
